# Canary example / canary の見本

This ticket is an example. Its `sourceSha` is the main of the day it was written, not today's main. Before the first real bridge run, write a fresh ticket against current main and check it with `node scripts/ix-job.mjs check-request`. See `docs/dev-loop.md`.

この票は見本です。`sourceSha` は書いた日の main で、今の main ではありません。最初に本物の橋を動かす前に、今の main に対して新しい票を書き、`node scripts/ix-job.mjs check-request` で確かめてください。`docs/dev-loop.md` を見てください。
